Privacy Policy

Last updated: July 27, 2026

This Privacy Policy explains what data the automated content publishing tool operated for the "Tui dau tu" channel (the "Service") accesses, how it is used, and how it is stored, in connection with its use of third-party publishing APIs (including TikTok's Content Posting API, Meta's Graph API, and the YouTube Data API).

1. Data We Access

When the operator connects an account to the Service, it may access:

  • An OAuth access token and refresh token issued by the platform after the operator explicitly authorizes the connection.
  • A platform-issued user identifier (e.g. TikTok's open_id), used only to address API calls to the correct account.
  • Basic account/creator information required by the platform's publishing API (e.g. available privacy level options).

The Service does not request or access any data beyond what is required to publish video content to the operator's own connected account.

2. How We Use Data

Access tokens are used solely to authenticate API requests that publish video content generated by the operator to the operator's own connected account. No data collected through these APIs is sold, shared, or used for advertising, profiling, or any purpose other than operating the Service as described above.

3. Data Storage & Retention

Access tokens and refresh tokens are stored locally on infrastructure controlled by the operator and are not transmitted to any third party other than the platform that issued them (for the purpose of refreshing or using the token). Tokens are retained only for as long as the Service continues to publish to the connected account.

4. Revoking Access

The operator can revoke the Service's access to any connected platform at any time from that platform's own account/app-permissions settings (for example, TikTok's "Manage apps" page, or Facebook's "Business Integrations" settings). Once access is revoked, the corresponding locally stored tokens are deleted and no further API calls are made on behalf of that account.

5. Third-Party Services

The Service interacts with third-party platform APIs (TikTok, Meta/ Facebook, YouTube/Google) solely to publish content. Each platform's own privacy policy governs its handling of any data processed on its servers.

6. Changes to This Policy

This Privacy Policy may be updated from time to time. Continued use of the Service after changes are posted constitutes acceptance of the revised policy.
